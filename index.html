EDUCATIONAL DEMO

Browser & device diagnostics

This demo records basic technical diagnostics after you give permission. It does not read cookie values, passwords, browser history, or data belonging to other websites.

What will be sent?

  • Public IP address (observed by the cloud server)
  • Browser/OS hints, user-agent, device and screen details
  • Timezone and preferred language
  • Names and counts of storage entries on this website only
  • Names of cookies visible to this website only (not their values)
  • Names of IndexedDB databases on this website only

Do not continue on a shared or sensitive device. Your report is stored in the project owner's cloud database. After submission, you will be redirected to Amazon India.

No passwords, cookie values, session tokens, form contents, or storage values are collected.
